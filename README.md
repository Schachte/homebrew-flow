# Flow for Homebrew

Flow turns a source folder into source-linked C4 architecture diagrams on macOS (Apple silicon, macOS 15+).

## Install

```sh
brew install --cask schachte/flow/flow
```

That one command adds this tap and trusts only the `flow` cask (Homebrew 6+ asks you to trust non-official taps).

## Upgrade

```sh
brew upgrade --cask flow
```

Quit and reopen Flow afterwards if it was running.

## Coming from Contour

Flow was called Contour before 0.3.0. It moves Contour's workspaces and settings over on first launch. Switch with:

```sh
brew uninstall --cask contour && brew install --cask schachte/flow/flow
```

## Uninstall

```sh
brew uninstall --cask flow         # the app
brew uninstall --cask --zap flow   # also workspaces, logs and settings
```

## Notes

- Builds are ad-hoc signed and not notarized. The cask clears the Gatekeeper quarantine flag after installing so the app opens; if macOS still blocks it, run `xattr -dr com.apple.quarantine /Applications/Flow.app`.
- Agent features use a coding-agent CLI you install and sign in to separately: Codex, pi or OpenCode.
- Each release's DMG is attached to this repository's [releases](https://github.com/Schachte/homebrew-flow/releases).
- This tap is generated by the Flow source repo's `make release`; edit `macos/packaging/` there, not here.
